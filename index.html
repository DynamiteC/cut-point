Four-Stage Autonomous Pipeline

Each step in CutPoint is purpose-built: LLMs are used only for language and vision, while analytical math and video slicing remain 100% deterministic.

STAGE 01
Analyst Agent
Queries ClickHouse Cloud OLAP via FastMCP. Identifies retention changepoints (z-score ≥ 2.5) and cohort divergence in < 50ms.
ClickHouse SQL
STAGE 02
Extractor Agent
Deterministic HTTP microservice that triggers local or Cloud Run FFmpeg to slice a 10-second window centered on each detected cliff point.
FFmpeg / Cloud Run
STAGE 03
Diagnostician
Passes sliced MP4 clips to Vertex AI Gemini 2.5 Flash for multimodal frame-level perception (visual clarity, audio drop, narrative hook).
Gemini 2.5 Flash
STAGE 04
Reporter Agent
Compiles frame insights, changepoints, and timestamps into self-contained, interactive Director's Notes in JSON and HTML.
Jinja2 / JSON Schema

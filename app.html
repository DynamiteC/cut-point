Find the second when people stop watching.

The database finds the exact second when many people leave. Gemini then looks at those frames and says what is on the screen. This page shows the result. It reads the reports live from the service on Google Cloud. Pick a video below.

Run an analysis

Triggering an analysis is authenticated on purpose. Each run executes ClickHouse queries, an ffmpeg extraction per detected cliff and a Gemini video inference per clip, so POST /analyze requires a Google-signed identity token from an allowlisted service account. An anonymous call returns 401, which is the security model working rather than an outage. Reading reports needs no credential, which is why this page works. 

# anyone can read a report
curl …/report/demo_001

# starting a run costs money, so it needs an identity
curl -X POST …/analyze \
  -H "Authorization: Bearer $(gcloud auth print-identity-token)" \
  -H "content-type: application/json" \
  -d '{"trailer_id":"demo_001"}'
